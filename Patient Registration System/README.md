## Program Title

Patient Registration System

## Objective

To develop a PHP-based patient registration system that
collects patient details, validates the entered information,
and displays a confirmation report after successful
registration.

## Software/Tools Used

- HTML5
- CSS3
- PHP
- XAMPP
- Visual Studio Code
- Google Chrome
- GitHub

## Features

- Patient registration form
- Patient name collection
- Date of birth
- Gender selection
- Phone number
- Email address
- Blood group
- Department selection
- Address
- Emergency contact
- Server-side validation
- Error messages
- Successful registration message
- Confirmation report
- Responsive design
- Print confirmation report

## Validation

The application validates:

1. Patient name
2. Date of birth
3. Gender
4. Phone number
5. Email address
6. Blood group
7. Department
8. Address
9. Emergency contact number

## How to Run

1. Install XAMPP.
2. Start Apache from the XAMPP Control Panel.
3. Place the project folder inside the `htdocs` folder.
4. Open Google Chrome.
5. Enter:

http://localhost/PHP_HTML_CSS/Patient%20Registration%20System/

6. Enter the patient details.
7. Click "Register Patient".
8. The confirmation report will be displayed.
