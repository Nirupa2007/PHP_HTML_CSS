## Objective

The objective of this project is to design and develop a web-based
admission application system using HTML5, CSS3 and PHP.

The application collects applicant details, validates mandatory fields,
processes the submitted information and generates an admission
acknowledgement page.

## Software/Tools Used

- HTML5
- CSS3
- PHP
- XAMPP
- Visual Studio Code
- Google Chrome
- GitHub

## Features

- Applicant registration form
- Mandatory field validation
- Email validation
- Phone number validation
- Percentage validation
- PHP server-side validation
- Admission acknowledgement generation
- Unique acknowledgement number
- Print acknowledgement option
- Responsive user interface
- External CSS styling

## Applicant Details Collected

- Applicant Name
- Date of Birth
- Gender
- Email Address
- Phone Number
- Address
- Course Applied For
- Previous Qualification
- Previous Exam Percentage

## How to Run

1. Install XAMPP.
2. Start Apache from the XAMPP Control Panel.
3. Copy the project folder into the `htdocs` folder.
4. Open a web browser.
5. Open the project using:

http://localhost/PHP_HTML_CSS/Admission%20Application%20System/index.php

6. Enter the applicant details.
7. Click Submit Application.
8. The admission acknowledgement page will be displayed.
