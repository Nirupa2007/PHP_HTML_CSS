## Objective

To develop a web application using HTML, CSS, and PHP
that collects course registration details, validates
the user input, and displays the registration details
after successful submission.

## Software/Tools Used

- HTML5
- CSS3
- PHP
- XAMPP
- Visual Studio Code
- Google Chrome
- GitHub

## Features

- Student registration form
- Student name input
- Register number input
- Email validation
- Phone number validation
- Gender selection
- Course selection
- Course mode selection
- Address input
- Server-side validation using PHP
- Error messages
- Successful registration message
- Registration details display
- Responsive design
- Print registration details

## Validation

The application validates:

1. Student name
2. Register number
3. Email address
4. Phone number
5. Gender
6. Course
7. Course mode
8. Address

## How to Run

1. Install XAMPP.
2. Start Apache from the XAMPP Control Panel.
3. Place the project folder inside the `htdocs` folder.
4. Open Google Chrome.
5. Enter the following URL:

http://localhost/PHP_HTML_CSS/Course%20Registration%20System/

6. Enter the registration details.
7. Click "Register Now".
8. The registration details will be displayed.
