Restaurant Menu Web Page

## Objective

To design and develop a user-friendly and responsive
restaurant menu web page using HTML5 and CSS3. The web page
displays different food categories, food item prices and
restaurant ordering information.

## Software/Tools Used

- HTML5
- CSS3
- Visual Studio Code
- Google Chrome
- GitHub

## Features

- Restaurant header
- Food category navigation
- Starters section
- Main Course section
- Indian Breads section
- Desserts section
- Beverages section
- Food item descriptions
- Item prices
- Vegetarian and non-vegetarian indicators
- Ordering information
- Phone and email contact details
- Restaurant address
- Opening hours
- Responsive design
- Mobile-friendly interface
- External CSS

## Food Categories

The menu contains the following categories:

1. Starters
2. Main Course
3. Indian Breads
4. Desserts
5. Beverages

## How to Run

1. Open the project folder.
2. Open `index.html` in Google Chrome.
3. The restaurant menu will be displayed.
4. Use the navigation links to move between food categories.
5. Click "Call to Order" to contact the restaurant.
