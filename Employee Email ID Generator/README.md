## Program Title

Employee Email ID Generator

## Objective

The objective of this project is to develop a PHP application that
accepts employee names and automatically generates professional
employee email IDs using PHP string manipulation functions.

## Software/Tools Used

- HTML5
- CSS3
- PHP
- XAMPP
- Visual Studio Code
- Google Chrome
- GitHub

## Features

- Accepts employee name
- Accepts department
- Validates employee name
- Converts names to lowercase
- Removes extra spaces
- Splits names into words
- Generates a username
- Generates an employee email ID
- Displays the processed name
- Displays the generated email
- Responsive design
- External CSS
- Error messages

## String Functions Used

### trim()

Used to remove unnecessary spaces from the beginning
and end of the employee name.

### strtolower()

Used to convert the employee name to lowercase.

### preg_replace()

Used to remove unwanted characters and extra spaces.

### explode()

Used to split the employee name into individual words.

### end()

Used to obtain the last part of the employee name.

### ucwords()

Used to display the employee name with the first letter
of each word in uppercase.

## Email Format

The generated email follows this format:

firstname.lastname@abccompany.com

Example:

John Kumar

becomes:

john.kumar@abccompany.com

## How to Run

1. Install XAMPP.
2. Start Apache from the XAMPP Control Panel.
3. Copy the project folder into the htdocs folder.
4. Open a web browser.
5. Open:

http://localhost/PHP_HTML_CSS/Employee%20Email%20ID%20Generator/

6. Enter the employee name.
7. Select the department.
8. Click "Generate Email ID".
9. The generated email address will be displayed.
