## Program Title

Sales Calculator

## Objective

To develop a PHP-based sales calculator that accepts
product quantity and product price, calculates the total
sales value using a user-defined function, and displays
the result in a structured format.

## Software/Tools Used

- HTML5
- CSS3
- PHP
- Visual Studio Code
- XAMPP
- Google Chrome
- GitHub

## Features

- Accepts product name
- Accepts product quantity
- Accepts product price
- Validates user input
- Uses POST method
- Uses a user-defined PHP function
- Calculates total sales value
- Displays success message
- Displays appropriate error messages
- Responsive user interface
- Uses external CSS

## Formula

Total Sales Value = Product Quantity × Product Price

Example:

Quantity = 5

Price = ₹200

Total Sales Value = 5 × ₹200

Total Sales Value = ₹1000

## User-Defined Function

The application uses the following PHP function:

function calculateSalesValue($quantity, $price)
{
    return $quantity * $price;
}

## How to Run

1. Install XAMPP.
2. Start Apache from the XAMPP Control Panel.
3. Copy the "Sales Calculator" folder into the `htdocs` folder.
4. Open Google Chrome.
5. Enter:

http://localhost/Sales%20Calculator/

6. Enter the product name.
7. Enter the quantity.
8. Enter the product price.
9. Click "Calculate Sales".
10. The total sales value will be displayed.
