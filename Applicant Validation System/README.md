## Objective

## Validation Rules

### Email

The email must follow a valid email format.

Example:

student@gmail.com

### Password

The password must:

- Contain at least 8 characters
- Contain at least one uppercase letter
- Contain at least one lowercase letter
- Contain at least one digit

Example:

Student123

### Mobile Number

The mobile number must contain exactly 10 digits.

Example:

9876543210

## How to Run

1. Install XAMPP.
2. Start Apache from the XAMPP Control Panel.
3. Place the project folder inside the `htdocs` folder.
4. Open Google Chrome.
5. Enter:

http://localhost/PHP_HTML_CSS/Applicant%20Validation%20System/

6. Enter the applicant details.
7. Click "Validate Details".
8. The validation result will be displayed.
