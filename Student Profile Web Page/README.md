## Objective

To design and develop a responsive student profile web page
using HTML5 and CSS3 that displays academic details,
personal details and contact information in a user-friendly
layout.

## Software/Tools Used

- HTML5
- CSS3
- Visual Studio Code
- Google Chrome
- GitHub

## Features

- Personal details section
- Academic details section
- Contact information section
- Semester performance table
- Technical skills section
- Responsive design
- Mobile-friendly layout
- External CSS
- Semantic HTML5 elements

### Personal Details

- Full Name
- Date of Birth

- City

### Academic Details

- Semester performance
