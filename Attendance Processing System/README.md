## Objective

To develop a PHP-based Attendance Processing System using HTML5, external CSS, and PHP.

The application accepts student attendance details, calculates the attendance percentage, determines examination eligibility, validates user input, and displays appropriate success or error messages.

---

## Features

- Accepts student name and register number.
- Accepts total working days.
- Accepts number of days present.
- Calculates attendance percentage.
- Determines examination eligibility.
- Uses user-defined PHP functions.
- Validates input fields.
- Displays error messages for invalid input.
- Responsive user interface.
- Uses external CSS.

---

## Eligibility Criteria

A student is considered eligible for the examination if the attendance percentage is 75% or above.

### Formula

Attendance Percentage =

(Days Present / Total Working Days) × 100

---

## User-Defined Functions

The following functions are used:

1. `calculateAttendancePercentage()`
2. `checkEligibility()`
3. `getEligibilityClass()`
