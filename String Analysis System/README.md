## Program Title

String Analysis System

## Objective

To develop a PHP application that accepts a title from
the user and analyzes the string by counting vowels,
consonants, digits, and special characters using PHP
string manipulation functions.

## Software/Tools Used

- HTML5
- CSS3
- PHP
- XAMPP
- Visual Studio Code
- Google Chrome
- GitHub

## Features

- Accepts a title from the user
- Counts vowels
- Counts consonants
- Counts digits
- Counts special characters
- Uses PHP string functions
- Uses a user-defined function
- Uses decision-making statements
- Validates the input
- Displays error messages
- Displays analysis results
- Responsive interface
- Print result option

## String Functions Used

The following PHP string functions are used:

- `strlen()`
- `strtolower()`
- `ctype_alpha()`
- `ctype_digit()`
- `ctype_space()`

## Logic

1. The user enters a title.
2. The title is submitted using the POST method.
3. PHP validates the input.
4. The string is converted to lowercase.
5. Each character is examined using a loop.
6. Vowels are counted separately.
7. Alphabetic characters other than vowels are counted
   as consonants.
8. Numeric characters are counted as digits.
9. Special characters are counted separately.
10. Spaces are not counted as special characters.
11. The final result is displayed.

## How to Run

1. Install XAMPP.
2. Start Apache from the XAMPP Control Panel.
3. Place the project folder inside the `htdocs` folder.
4. Open Google Chrome.
5. Enter:

http://localhost/PHP_HTML_CSS/String%20Analysis%20System/

6. Enter a title.
7. Click "Analyze String".
8. The analysis result will be displayed.
