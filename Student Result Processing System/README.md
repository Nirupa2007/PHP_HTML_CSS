## Program Title

Student Result Processing System

## Objective

To develop a PHP application that accepts student marks,
calculates total marks and average marks, determines the
grade, and displays the student's result.

## Software/Tools Used

- HTML5
- CSS3
- PHP
- XAMPP
- Visual Studio Code
- Google Chrome
- GitHub

## Features

- Accepts student details
- Accepts marks for five subjects
- Calculates total marks
- Calculates average marks
- Determines grade
- Determines Pass/Fail status
- Uses PHP functions
- Uses if-else decision-making statements
- Validates input
- Displays error messages
- Responsive interface
- Print result option

## Grading System

| Average | Grade |
|---|---|
| 90 - 100 | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| 40 - 49 | E |
| Below 40 | F |

## Pass Criteria

A student must score at least 40 marks in every subject
to pass.

## How to Run

1. Install XAMPP.
2. Start Apache.
3. Place the project folder inside `htdocs`.
4. Open the browser.
5. Go to:

http://localhost/PHP_HTML_CSS/Student%20Result%20Processing%20System/

6. Enter the student details and marks.
7. Click "Calculate Result".
8. The result will be displayed.
